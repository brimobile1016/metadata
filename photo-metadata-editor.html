Photo Metadata Editor

Tambahkan metadata EXIF ke foto JPG/JPEG/PNG tanpa mengubah resolusi asli gambar.

Camera Information

Catatan:
Foto tidak diproses menggunakan Canvas dan tidak di-resize.
Resolusi asli seperti 4000 × 6000 tetap dipertahankan.
JPEG tidak di-encode ulang. PNG akan dikonversi otomatis ke JPEG dengan ukuran piksel yang sama sebelum metadata ditambahkan.

Alur otomatis:
Pilih Make / Merek HP → pilih Camera Model → metadata Make, Model, Software, Device Manufacturer dan Profile Copyright akan dibuat otomatis.

Untuk Xiaomi, metadata Xiaomi Model juga akan ditambahkan secara otomatis.
